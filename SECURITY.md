# Security policy

Mivlet is experimental, pre-release software. Security fixes target the latest
`main` revision; older snapshots are not supported release branches.

Please report suspected vulnerabilities privately using GitHub's
[Report a vulnerability](https://github.com/joshuasknott/mivlet/security/advisories/new)
form. If that form is unavailable, email joshhknott@gmail.com with the subject
"Mivlet security report". Do not open a public issue containing exploit details,
credentials, personal data, or private workspace contents.

Include the affected revision, reproduction steps using synthetic data, expected
and actual behavior, and impact. Remove real tokens and personal information.
Allow time for investigation and a fix before public disclosure.

For ordinary bugs and feature requests, use GitHub Issues. Provider credentials,
account authentication, native approvals, Stop, and computer-control boundaries
are security-sensitive; automated fixtures do not establish live safety.
