# Selected Direction

Source visual truth:

- Corrected concept: `docs/design/fable-ui-concept.png`
- Desktop implementation: `docs/design/qa/fable-after-1440x1024.png`
- Narrow implementation: `docs/design/qa/fable-after-390x844.png`

The selected Fable first screen blends the attached reference with these changes:

- Use the tokenized warm surface, graphite ink, and burnt-copper interaction palette.
- Keep the Fable dragon lockup above the workspace selector.
- Preserve the current navigation labels, order, hierarchy, and responsive grouping.
- Use Codex-like lightweight navigation: Chats and Projects are sections, each containing threads.
- Chats contain non-project threads.
- Projects contain project-specific threads nested under each project.
- Connectors, Knowledge, and Schedules are quiet secondary workspace tools.
- Do not include Home, Threads, or Goals as sidebar entries.
- Merge Settings and profile into one bottom account row.
- Remove right-side panels and right navigation.
- Keep a large welcoming center with a universal composer.
- The connector pills below the composer insert tool context into the composer.
- Connectors, Knowledge, Schedules, and Memory/Approvals open as focused main-canvas views, not as a right nav.
- Persist local drafts and decisions so restart recovery can be demonstrated before the encrypted runtime store is wired.
