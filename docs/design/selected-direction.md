# Selected Direction

Source visual truth: `docs/design/praxis-selected-concept.png`.

The selected Arden first screen blends the attached reference with these changes:

- Use a Cursor-like neutral palette: graphite shell, off-white workspace, low-saturation accent colors.
- Use Codex-like lightweight navigation: Chats and Projects are sections, each containing threads.
- Chats contain non-project threads.
- Projects contain project-specific threads nested under each project.
- Knowledge, Plugins, and Automations are quiet secondary workspace tools.
- Do not include Home, Threads, or Goals as sidebar entries.
- Merge Settings and profile into one bottom account row.
- Remove right-side panels and right navigation.
- Keep a large welcoming center with a serif editorial headline and a universal composer.
- The cards below the composer are single clickable prompt starters. Clicking one writes its directive into the composer.
- Knowledge, Plugins, Automations, and Memory/Approvals open as focused main-canvas views, not as a right nav.
- Persist local drafts and decisions so restart recovery can be demonstrated before the encrypted runtime store is wired.
