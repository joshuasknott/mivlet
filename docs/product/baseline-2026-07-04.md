## Confirmed Architecture Facts

- Desktop is Tauri 2 + React 19 + TypeScript/Vite, with Rust owning native commands, scheduler, connector/auth boundaries, keyring access, HTTP egress, and encrypted local persistence.
- Local production persistence uses bundled SQLite plus application-layer AES-256-GCM. The 32-byte master key lives in OS secure storage through the `keyring` crate. Credentials and OAuth tokens are stored separately in OS secure storage, not in SQLite.
- The monorepo includes desktop, broker, marketing, and waitlist apps; connector, knowledge, and protocol packages.
- The broker is implemented as a runtime-neutral OAuth broker with Node and Cloudflare Worker transports. Worker durable mode has Durable Object classes, bindings, migrations, encryption helpers, and tests; default storage remains `memory`. Production deployment, provider secrets, durable-mode secret configuration, callback registration, and live OAuth validation are not present.
- Google Drive/Gmail/Calendar use direct desktop public-client OAuth with PKCE and `FABLE_GOOGLE_OAUTH_CLIENT_ID`; they do not use the confidential broker.
- Confidential connectors are GitHub, Vercel, Notion, Slack, and Linear. They are implemented/gated by broker configuration. GitHub live surface is read-only; Notion, Slack, Linear, Vercel, and Google write paths are approval-gated where implemented. External certification and live-provider validation are not in the repo.
- Clerk/hosted identity is not implemented or required for local-first desktop use. No Clerk package or code was found in source.
- Convex is a dependency with a tiny optional client factory using `VITE_CONVEX_URL`; no Convex schema or sync/collaboration contract was found.
- No TanStack dependency or source usage was found outside installed dependencies.
- Release is Windows-preview oriented and unsigned. No updater channel, signing pipeline, macOS packaging, Linux packaging, or cross-platform keychain CI was found.
- Local model execution is planned/disabled; native BYOK provider execution exists for OpenAI-compatible, Anthropic, Gemini, xAI, and OpenRouter paths.
