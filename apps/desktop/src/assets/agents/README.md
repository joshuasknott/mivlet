# Agent characters

Eight original raster shells generated with the built-in imagegen tool, using
the user's supplied robot character sheet as a style reference. Transparent PNGs
are kept as generated. Faces deliberately have no baked-in eyes: the shared
`AgentAvatar` SVG layer supplies expressions without changing identity or colour.
Uploaded portraits never receive synthetic eyes, recolouring, or character motion.

Generation prompt shared by the eight assets:

> Use case: stylized-concept. One production robot avatar asset. The attached
> image is a style reference only. Soft premium 3D clay robot head only, no body.
> Straight-on centred front view, head entirely visible, filling 88% of a square.
> Large dark blank face screen centred horizontally, face centre near 58% height.
> No eyes, mouth, or markings on the screen; the app overlays animated eyes.
> Actual transparent alpha background, no tile, external shadow, checkerboard,
> or text. Match the cute tactile soft shells. Distinct silhouette legible at 32px.
