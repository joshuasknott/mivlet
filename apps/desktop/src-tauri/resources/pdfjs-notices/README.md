# PDF preview notices

Mivlet bundles PDF.js 6.4.299 from Mozilla's `pdfjs-dist` package, its standard
fonts and Adobe character maps for offline page rendering. The library and
worker retain their license headers. Upstream notices are redistributed
here: PDF.js (Apache-2.0), Liberation fonts, Foxit fonts and Adobe CMaps.

License text only normalizes trailing whitespace.

When updating `pdfjs-dist`, refresh these notices from the same installed version.
